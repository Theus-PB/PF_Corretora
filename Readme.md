# Valdice Alves | Corretora de Imóveis

Site institucional desenvolvido para a **Valdice Alves – Corretora de Imóveis**, com o objetivo de apresentar a empresa, divulgar imóveis disponíveis e facilitar o contato com clientes interessados em compra, venda e aluguel de imóveis.

O projeto foi desenvolvido como parte dos estudos de **Ciência da Computação**, com foco na aplicação prática de conceitos de desenvolvimento Front-End.

## Sobre o projeto

O site apresenta uma estrutura organizada e uma identidade visual voltada ao mercado imobiliário, buscando transmitir profissionalismo, credibilidade e facilidade de navegação.

A plataforma reúne informações sobre a corretora, empreendimentos disponíveis, imóveis para aluguel e canais de atendimento.

## Funcionalidades

- **Página inicial:** apresentação da corretora, destaques de imóveis e área de pesquisa.
- **Sobre:** apresentação da empresa e informações institucionais.
- **Imóveis à venda:** catálogo de empreendimentos disponíveis para compra.
- **Imóveis para aluguel:** página dedicada aos imóveis disponíveis para locação.
- **Detalhes dos imóveis:** apresentação de características, imagens, descrições e informações dos empreendimentos.
- **Contato:** formulário para preenchimento de informações e canais de atendimento.
- **Página de agradecimento:** confirmação visual após o envio do formulário.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo das páginas.
- **CSS3:** estilização, identidade visual, organização dos elementos e formatação das páginas.

## Identidade visual

O projeto utiliza uma identidade visual baseada em tons escuros, com detalhes em champagne, buscando transmitir elegância e sofisticação.

A organização das páginas prioriza a leitura das informações, a apresentação dos imóveis e o acesso aos canais de contato.

## Observações

O formulário de contato possui funcionamento demonstrativo: após o preenchimento dos campos obrigatórios, o usuário é direcionado para uma página de agradecimento.

Os dados preenchidos não são armazenados nem enviados para a corretora, pois o projeto não possui integração com banco de dados ou serviço de processamento de formulários.
